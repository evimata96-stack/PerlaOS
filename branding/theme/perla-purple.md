# Tema Perla-purple

## Paleta oficial

| Nombre              | Hex       | Uso principal                     |
|---------------------|-----------|-----------------------------------|
| Violeta profundo    | `#4B2E83` | Fondo principal, sidebar          |
| Violeta medio       | `#7B4FA6` | Acentos secundarios               |
| Acento brillante    | `#C084FC` | Highlights, botones activos       |
| Blanco perlado      | `#F5F0FA` | Texto principal, fondos claros    |
| Gris perla          | `#E8E0F0` | Fondos secundarios                |
| Oscuro base         | `#1A1025` | Fondos oscuros del escritorio     |

## Recomendaciones GTK / GNOME

- Tema base: **Adwaita-dark** personalizado
- Color de acento de GNOME: `#C084FC`
- Iconos: Adwaita (redondeados) o Papirus con tinte violeta
- Cursor: Adwaita
- Fuente: Noto Sans / Noto Sans Mono

## Wallpaper por defecto

- Nombre: `perlaos-default.jpg`
- Descripción: Onda luminosa violeta sobre fondo oscuro profundo, con sutil brillo perlado en el centro.
- Resolución objetivo: 3840×2160 (4K) + versiones 1920×1080
